# Syntecxhub_Online_Shopping_Cart

# Online Shopping Cart (Java)
A console-based Online Shopping Cart application developed using **Core Java**, **ArrayList**, and **HashMap**.  
This project demonstrates effective use of Java Collections and menu-driven programming.

# Features
1. View available products with prices
2. Add products to cart (case-insensitive)
3. Manage item quantities using HashMap
4. View cart items
5. Calculate total bill amount
6. User-friendly menu-driven interface

# Technologies Used
1. Java (Core Java)
2. ArrayList
3. HashMap
4. Scanner (User Input)

# Project Structure

online_shopping_cart/ Shopping_Cart.java

# Learning Outcomes
1. Understanding Java Collections Framework
2. Using HashMap for key–value data management
3. Implementing real-world logic using Java
4. Handling user input and validations
5. Writing clean and modular code
